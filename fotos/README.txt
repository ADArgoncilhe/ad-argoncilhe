FOTOGRAFIAS DO PLANTEL - AD ARGONCILHE APP

Coloque aqui as fotografias dos jogadores.

O nome do ficheiro é criado automaticamente a partir do nome apresentado no campo "role" do jogador.

Exemplos:
Francisco Oliveira -> francisco-oliveira.jpg
Vicente Lopes -> vicente-lopes.jpg
Tomás Silva -> tomas-silva.jpg
Valentino Félix -> valentino-felix.jpg

Formato recomendado: JPG, preferencialmente fotografia vertical/rosto.

Para adicionar um jogador:
1. Copie uma linha dentro de "const players = [ ... ]".
2. Altere número, função/nome e URL.
3. Coloque a fotografia correspondente nesta pasta com o nome gerado automaticamente.

Não é necessário alterar mais nada no código.
